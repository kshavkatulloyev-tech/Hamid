# Сплит-экран шаблони — йўриқнома

Вертикал видео (1080×1920, 30 кадр/сония, 24 сония). Тузилиши:

| Вақт | Нима кўринади |
|---|---|
| 0–3 с | Сиз тўлиқ экранда + савол («Белингиз оғрийдими?») |
| 3–19 с | Тепада анимация (умуртқа → 3 та маслаҳат), пастда сиз, ўртада субтитр |
| 19–24 с | Якун: логотип, шиор, телефон, манзил |

## Ўз видеонгизни қўйиш
1. Телефонда **вертикал** олинг. Юзингиз кадр ўртасида, тепада бир оз бўш жой қолсин.
2. Файлни `assets/presenter.mp4` номи билан алмаштиринг (ҳозиргиси — «СИЗНИНГ ВИДЕОНГИЗ» деган намуна).
3. Видео 24 сониядан узун бўлса, кейинги қисми кесилади.

## Матнни ўзгартириш
- Савол: `compositions/hook.html` → `hookTitle`
- Мавзу, сабаб, 3 та маслаҳат: `compositions/split.html` → `topic`, `causeBig`, `tip1`…`tip3`
- Субтитрлар ва уларнинг вақти: `compositions/captions.html`
- Телефон, манзил, шиор: `compositions/cta.html`
